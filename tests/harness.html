SnapTable OCR pipeline test (dev tool — not part of the shipped extension)

Serves the real src/shared/tesseract.min.js + src/shared/snaptable-ocr.js files unmodified, with a tiny shim for chrome.runtime.getURL so they resolve paths against this static server instead of a chrome-extension:// origin. Run with:
python -m http.server 8850 --directory "<path to SnapTable-OCR>"
then open http://localhost:8850/tests/harness.html.
